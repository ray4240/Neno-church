# ⛪ Neno Evangelism Centre & Sasa TV Network Web Portal

A modern, responsive, cathedral-inspired web platform built for **Neno Evangelism Centre** (led by Apostle Dr. James Maina Ng'ang'a) and integrated with **Sasa TV Network**.

🌐 **Live Production URL:** [https://neno-church.vercel.app](https://neno-church.vercel.app)

---

## ✨ Key Features

- **Hero Slideshow Background:** Immersive multi-image full-screen slideshow showcasing ministry moments.
- **Sasa TV Live Broadcast Hub:** Direct access to live YouTube streams, service schedules, and media archives.
- **Church Branches Directory:** Detailed locations and service times for Nairobi HQ, Mombasa, Thika, Kisumu, Nakuru, and Githurai branches.
- **Interactive Giving Portal:** Easy mobile M-Pesa Paybill (`727428`) and Buy Goods Till (`263853`) details with copy-to-clipboard functionality.
- **WhatsApp Prayer Line Form:** Direct user prayer submission form integrated with WhatsApp messaging routing.
- **Cathedral-Styled Footer:** Comprehensive directory layout inspired by All Saints' Cathedral, complete with social media handles.

---

## 🛠️ Tech Stack

- **Styling:** Tailwind CSS CDN
- **Icons:** FontAwesome
- **Interactivity:** Vanilla JavaScript
- **Hosting & Deployment:** Vercel
